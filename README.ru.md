# tron-cold-wallet-offline

TRON USDT холодный кошелёк — тулкит для **офлайн-машины**.

Генерация кошелька и подпись транзакций в воздушном зазоре. Интернет не нужен после `npm install`.

Часть двухмашинного воздушного зазора:

```
[Онлайн-машина] ──► unsigned_tx.json ──► [Офлайн-машина]
[Онлайн-машина] ◄── signed_tx.json   ◄── [Офлайн-машина]
```

## Возможности

- Генерация нового TRON-кошелька (BIP39 24-слова, BIP32/BIP44 HD-деривация)
- Восстановление кошелька из мнемоники с деривацией приватного ключа в RAM
- Подпись неподписанных USDT TRC-20 транзакций — ключ никогда не касается диска или сети
- Поддержка нескольких кошельков из одной мнемоники через индекс

## Подготовка офлайн-машины

### Вариант A: выделенный ноутбук

После чистой установки Ubuntu/Debian — отключить сеть навсегда:

```bash
sudo systemctl disable --now NetworkManager
sudo systemctl disable --now wpa_supplicant
sudo rfkill block all
```

Убедиться что сеть мертва:

```bash
ip link show  # все интерфейсы должны быть DOWN
ping 8.8.8.8  # должен упасть
```

### Установка Node.js

На **онлайн-машине** скачать бинарник Node.js (установщик не нужен).  
Актуальную версию LTS и SHA-256 хеш смотреть на https://nodejs.org/en/download/

```bash
wget https://nodejs.org/dist/vX.Y.Z/node-vX.Y.Z-linux-x64.tar.xz

# Проверить контрольную сумму — сравнить с хешем на nodejs.org
sha256sum node-vX.Y.Z-linux-x64.tar.xz
```

Скопировать архив и папку проекта (включая `node_modules`) на USB.

На **офлайн-машине**:

```bash
tar xf node-vX.Y.Z-linux-x64.tar.xz
export PATH=$PWD/node-vX.Y.Z-linux-x64/bin:$PATH

# Для сохранения между сессиями добавить в ~/.bashrc:
# echo 'export PATH=/path/to/node-vX.Y.Z-linux-x64/bin:$PATH' >> ~/.bashrc

node --version
```

## Установка

Запустить `npm install` **до отключения от интернета** — `node_modules` должен быть скопирован на офлайн-машину.

```bash
git clone https://github.com/ivanrmnvch/tron-cold-wallet-offline.git
cd tron-cold-wallet-offline
npm install
# Скопировать всю папку (с node_modules) на USB
# На офлайн-машине npm install не нужен
```

## Использование

### Генерация кошелька

```bash
node src/generate-wallet.js
```

Выводит 24-словную мнемонику, TRON-адрес и приватный ключ.

**Записать мнемонику на бумагу. Никогда не сохранять в цифровом виде.**  
После записи: `clear && history -c`

### Восстановление кошелька / деривация приватного ключа

```bash
node src/restore-wallet.js
```

Поддерживает индекс кошелька для нескольких адресов из одной мнемоники  
(`m/44'/195'/0'/0/<индекс>`). По умолчанию — индекс 0.

### Подпись транзакции

Скопировать `unsigned_tx.json` с онлайн-машины через USB, затем:

```bash
node src/sign-raw.js
```

Скрипт:
1. Читает и отображает детали транзакции (адрес получателя, сумма в USDT)
2. Верифицирует совпадение метаданных с байтами сырой транзакции — обнаруживает подмену
3. Запрашивает подтверждение
4. Запрашивает приватный ключ (интерактивный ввод, не сохраняется на диск)
5. Проверяет соответствие ключа адресу отправителя
6. Подписывает и записывает `signed_tx.json`

Скопировать `signed_tx.json` обратно на онлайн-машину и отправить.

## Модель безопасности

| Свойство | Описание |
|----------|---------|
| Хранение приватного ключа | Только RAM — вводится интерактивно, на диск не пишется |
| `signed_tx.json` | Содержит только подписанную транзакцию — без приватного ключа |
| Обнаружение подмены | `sign-raw.js` декодирует и сверяет байты сырой транзакции с метаданными |
| Сеть | Эта машина не должна подключаться к интернету |

Рекомендуется: полнодисковое шифрование (LUKS), `clear && history -c` после каждой сессии.

## Зависимости

Вся криптография реализована через проверенные аудитом, минималистичные библиотеки [Paul Miller](https://github.com/paulmillr):

| Пакет | Назначение |
|-------|------------|
| `@noble/curves` | secp256k1 ECDSA подпись |
| `@noble/hashes` | SHA-256, Keccak-256 |
| `@scure/bip32` | BIP32 HD-деривация ключей |
| `@scure/bip39` | BIP39 генерация и валидация мнемоники |
| `@scure/base` | Base58Check кодирование адресов |
